# Fonts

Bundled so the app works offline. The same families as the website.

- `Satoshi-Variable.woff2`: Satoshi by Indian Type Foundry, from Fontshare, under the ITF Free Font License (free for personal and commercial use).
- `DMSans-Variable.woff2`: DM Sans, latin subset (from `@fontsource-variable/dm-sans` 5.3.0), under the SIL Open Font License 1.1 (`DMSans-OFL.txt`).
